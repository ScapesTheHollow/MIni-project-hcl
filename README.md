## Requirements

- [Python 3.9 or newer](https://www.python.org/downloads/) (on Windows, tick **"Add Python to PATH"** during install)
- A web browser

## How to use it (step by step)

### 1. Get the project

Option A: with Git
```bash
git clone https://github.com/<your-username>/<your-repo-name>.git
cd <your-repo-name>
```

Option B: without Git. On the GitHub page click **Code → Download ZIP**, unzip it, and open a terminal **inside the unzipped folder**.

### 2. Install the dependencies
```bash
pip install -r requirements.txt
```

### 3. Start the app
```bash
python app.py
```
You should see `Running on http://127.0.0.1:5000`. Keep this terminal open.

### 4. Open it in your browser

Go to **http://127.0.0.1:5000**
